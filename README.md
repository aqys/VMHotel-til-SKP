# VMHotel-SKP

## Om projektet
VMHotel-SKP er en selvbetjeningsportal til Proxmox, hvor elever kan oprette og administrere virtuelle maskiner. Instruktører kan se og administrere elevernes VM’er.

Login og brugerroller håndteres gennem Active Directory.

## Konfigurationer

Cisco konfigurationerne er gemt, så de hurtigt kan gennemgås og bruges til at genskabe den eksisterende opsætning. Passwords i konfigurationerne er erstattet med placeholders. Husk derfor at ændre disse ved genskabelse af konfigurationen.

Proxmox konfigurationerne viser, hvordan vores Proxmox server håndterer netværkstrafikken og de forskellige netværksinterfaces/VLANs.
