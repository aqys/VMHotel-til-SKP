# VMHotel-SKP

## Om projektet

VMHotel-SKP er en selvbetjeningsportal til Proxmox. Elever kan oprette og administrere virtuelle maskiner.

Login og brugerroller håndteres gennem Active Directory.

## Konfigurationer

Cisco konfigurationerne er gemt, så de kan gennemgås og genskabes. Passwords er erstattet med placeholders. Husk at ændre dem, hvis konfigurationen genskabes.

Proxmox konfigurationerne viser, hvordan Proxmox serverne håndterer interfaces og VLANs.
